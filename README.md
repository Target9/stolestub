# Stolestub

3D-printable school-chair floor glides (skolestub), with a realistic fit model and a stress-resistant rebuild.

## Variants

| Folder | STL | Purpose |
|--------|-----|---------|
| [`realistic/`](realistic/) | `skolestub_realistic.stl` | Shape-matched to the real slipper / tunnel-on-flange glide |
| [`stress_resistant/`](stress_resistant/) | `skolestub_reinforced.stl` | Thick, filleted, overbuilt version after thin prints shattered |

Also included: matching `.obj` meshes, generators (Python / OpenSCAD), fit/stress reports, and preview images.

## Quick print

1. Slice the STL for the variant you want.
2. Orient **on its side** so the arch is continuous filament loops.
3. Prefer **PETG / ABS / ASA**, 4–6 walls, solid-ish gyroid infill.

See each folder’s README for dimensions, fit tweaks, and print settings.
